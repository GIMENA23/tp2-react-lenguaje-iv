# TP2 - Lenguaje IV (React + Vite)

Sitio con 3 páginas estáticas (Inicio, Servicios, Contacto), menú de
navegación y estilos, hecho con React y Vite.

## Cómo correrlo en tu máquina

```
npm install
npm run dev
```

## Cómo publicarlo en GitHub Pages

Ver instrucciones completas en la conversación con Claude. En resumen:

1. Editar `vite.config.js` y `src/main.jsx`: reemplazar `NOMBRE-DEL-REPO`
   por el nombre real del repositorio de GitHub.
2. Editar `package.json`: reemplazar `TU-USUARIO` y `NOMBRE-DEL-REPO`
   en el campo `homepage`.
3. `npm install`
4. `npm run deploy`
